# 留学规划助手 · Study Abroad Planner

当前包为 **0.10.0-pilot.3 试用版**，未作为公开稳定版发布。保留原学校 MCP，新增 19 张经验方法卡与 7 张官网核对事实卡，可用包内查询工具按问题检索；没有处理完全部 381 篇，也没有把这些卡片写入远程学校库。安装使用当前完整包，详情见 [知识查询](references/knowledge-query.md)。

**从选校到申请准备，把留学信息变成可执行的下一步。**

告诉 AI 你的背景、预算和入学目标，它会帮助你比较院校与专业、参考相似背景案例、找出申请差距，整理成可以继续修改的方案；需要时，还能打开在线顾问。

[让 AI 安装最新版](INSTALL.md) · [在线顾问](https://hi.xwoork.cn)

## 你可以得到什么

| 你现在遇到的问题 | 助手会做什么 | 最终得到什么 |
| --- | --- | --- |
| 不知道去哪、怎么选专业 | 结合学历、成绩、预算和毕业目标，查询候选院校与专业 | 有选择理由的候选清单，以及下一步要补充的信息 |
| 想知道自己的背景够不够 | 对比项目要求，参考相近背景的匿名案例，说明判断依据 | 条件差距表、冲刺 / 匹配 / 保底参考和具体补强建议 |
| 几个项目各有优劣 | 比较学制、学费、语言要求、排名和个人偏好 | 并排对比表，帮助你做取舍 |
| 不清楚要准备多少钱、什么时候行动 | 分开计算学费、生活费与一次性支出，倒排准备任务 | 预算表、时间线和近期行动清单 |
| 材料、文书、面试无从下手 | 整理材料缺项，用真实经历梳理文书，准备面试问题 | 材料清单、文书提纲、面试练习和修改方向 |
| 收到多个 offer 不知道怎么选 | 按你在意的费用、课程、就业与生活因素比较 | 有理由的 offer 决策表 |
| 希望进一步与真人沟通 | 在支持的应用中打开在线咨询页面 | 可继续沟通的顾问入口 |
| 咨询页无法使用麦克风 | 引导在系统浏览器配对通话助手 | 原页面继续看聊天和资料，助手窗口负责本次通话声音 |

## 不止是一段聊天

需要完整方案时，可以生成：

- **可筛选的网页报告**：按内容、状态和关键词查看。
- **Markdown 报告**：方便继续让 AI 修改或放进笔记。
- **CSV 表格**：可直接用 Excel 或其他表格软件打开。
- **Excel 工作簿**：安装可选导出依赖后生成。
- **结构化方案文件**：保留来源、核验时间和待补充项，便于后续更新。

只生成你需要的部分，单次问答不强制填写一整套表格。示例数据与真实查询结果分别标明。

## 把这个页面发给 AI，即可开始安装

复制下面这段话给支持本地文件与命令执行的 AI：

> 帮我安装留学规划助手 github:luluchu857/study-abroad-planner，按仓库说明完成配置，并检查能否正常使用。

不用填写版本号。AI 按本仓库的公开更新目录选择最新可用版本，安装后报告实际版本；如果它属于试用版，会明确说明。仅在你要求“只安装稳定版”时选择稳定通道。已有更新的本地版本会保留，不会降级。

支持 **Codex、WorkBuddy**，其他兼容 Skill 的应用可按说明选择安装目录。首次安装优先配置原生 MCP，已有连接直接复用；原生连接无法安装或只读连接故障时，使用包内的 **Python 直连客户端**访问同一服务。申请助手需要个人授权，换用 Python 不会绕过授权。

## 保持更新

每次使用时自动在后台检查；有兼容新版就下载、校验并保留旧版，下一次使用自动采用新版。当前咨询继续使用原来的完整版本，离线、下载失败或 GitHub 暂时限流都不打断咨询。正式版只接收正式更新；试用版可接收更高的试用版或正式版，绝不自动降级。已有知识条目和能力缺失、或者发现本地自定义修改时，会保留当前版本。

正常检查间隔为 6 小时；失败会按较短间隔退避，服务要求等待时遵守其时间。更新目录通过官方 GitHub 静态地址读取，不依赖 GitHub API 匿名查询额度。旧版用户需要先安装一次新入口，随后才能自动升级。需要宿主允许运行包内 Python 脚本；不支持执行脚本的应用仍可正常咨询，更新需要按安装指南处理。

## 在线顾问

需要真人协助，打开 [在线顾问](https://hi.xwoork.cn)。在支持内嵌浏览器的 Codex、WorkBuddy 中，助手会按咨询场景打开页面。

打开页面不会自动发送你的背景、方案或材料；实际沟通与材料提交由你在页面中完成。

### 原页面看资料，系统浏览器负责声音

通话助手已上线。咨询页面优先使用应用原生麦克风。确实受限或你选择助手时，可在 Chrome、Edge、Safari 等系统浏览器打开 [通话助手](https://hi.xwoork.cn/voice-helper)，**不用安装额外的语音程序**。

1. 保持原咨询页面打开，在助手点「准备配对」，取得 10 位配对码。
2. 回原咨询页填写并确认配对码，再到助手点「启用语音」，按浏览器提示允许麦克风。
3. 在原咨询页开始或接听本次通话。助手提供静音、声音播放与停止 / 挂断；网页不能替你跳过系统权限。

如果系统权限提示仍在等待，先完成或取消它，不因为等待就重复打开助手。配对和页面打开不等于通话已接通；以双方实际声音与页面状态为准。此次新助手已完成合成链路验证，真实设备及各版本 WorkBuddy 的通话效果仍需分别验收。[使用与排障说明](references/voice-calling.md)
