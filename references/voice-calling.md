# 通话说明：网页原生麦克风

联合招生官咨询页的语音一律由网页自己使用麦克风。本 Skill 不再准备、启动或关联任何本机通话助手，也不生成私有交接文件或配对码。

- 学生在咨询页里拨打或接听；系统询问麦克风权限时由学生本人允许，明确拒绝就不换路径绕过。
- WorkBuddy 的 `present_files` 产物预览可能拒绝麦克风，而 WorkBuddy 浏览器（“+ → 打开浏览器”）或系统浏览器可以正常取麦。页面提示无法开麦时，告诉学生在这两种浏览器打开同一地址（`https://hi.xwoork.cn/student`）。不承诺某个预览窗口一定能语音。
- 语音不可用不影响文字、文件和问卷，继续咨询即可；不反复弹修复提示，学生主动重试再说明。
- 页面可见、权限允许、实际双向声音、挂断停麦是不同状态；没有看到对应结果不说已接通。
- Skill 与安装检查都不开麦、不拨号；旧版遗留的本机助手可由用户自行卸载，Skill 不再调用它。
